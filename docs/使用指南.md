# MusicOne Windows 1.0.0

基于 [HGODLK/MusicOne](https://github.com/HGODLK/MusicOne) 的独立 Windows 桌面适配版，非原作者官方发行版。

## 运行

适用于 Windows 10 / Windows 11，64 位（x64）。已在 Windows 10 22H2（19045）验证普通桌面启动、本地播放、进度拖动、歌词和歌单，并在登录账号下验证 QQ 音乐库自动读取及在线播放。当前为 1.0.0 正式版。

升级时先退出旧版本，再启动新版；原有登录和本机歌单保存在同一用户目录。

解压完整便携包，在文件夹中双击 **MusicOne.exe**。必须保留同目录的 resources、locales、DLL 等文件，不能只取走 exe。

不需要安装 Android 模拟器、Java、Python 或 Node.js。程序没有申请管理员权限，也没有配置开机启动。

## 已实现的功能

- 歌词页退出时封面缩回与整页淡出共用同一时长，保持结束画面直到窗口恢复，避免控件和歌词闪回。
- 登录读取 QQ 音乐库后，左侧“我的歌单”自动列出 QQ 自建歌单，点击直接读取云端歌曲。与本机歌单分组显示，支持长列表滚动；刷新音乐库更新名称和列表，退出 QQ 账号后移除云端入口。

- 歌词页返回图标与点击区域居中；循环 / 随机图标统一白色，并隐藏该页的播放队列按钮（普通底栏保留）。
- 歌词采用当前行清晰、相邻行淡化、远处加深模糊的动态层次；翻译字号为原歌词的 80%，逐字明暗对比和当前字词柔光加强。逐字效果仅在音源提供真实字词时间时生效。

- 深色主题采用接近 GPT 深夜模式的中性灰黑：主背景 #212121，侧栏约 #171717，面板和底栏带半透明磨砂层次。
- 歌词页隐藏导入 LRC 和歌词行数；原音质文字位置改为音量按钮，点击展开音量条，点击空白处或按 Esc 收起。音质仍可在普通底栏查看。

- 夜间模式默认跟随 Windows 的应用浅色 / 深色设置；软件打开期间系统颜色变化会立即生效。设置 → 外观可手动选择浅色、深色或跟随 Windows，选择会保存。
- 点击底部专辑封面或“词”进入真正的全屏歌词布局。封面从底栏平滑放大，同一套播放按钮和进度条移动到封面下方，画面不留旧底栏缝隙。按 Esc 或左上角返回按钮退出，并还原原先的窗口状态。

- 参考原版浅色首页与沉浸歌词页重建的桌面界面。
- 选择文件或递归扫描文件夹，导入本地音乐；重复文件自动合并。
- MP3、FLAC、WAV、M4A、AAC、OGG、OPUS、WebM、MP4 等常见格式（最终取决于内置解码器）。
- 播放、暂停、切歌、进度拖动、音量、随机播放、单曲循环、播放队列。
- 本机收藏、自建歌单、歌单增删、歌曲移出列表。移出列表不会删除电脑上的原文件。
- 自动读取与音乐同名的 UTF-8 LRC 文件；支持滚动同步和点击歌词跳转；歌词页已隐藏手动导入入口。
- QQ 音乐登录后自动显示“我喜欢”、自建歌单和收藏歌单，点开即可播放，无需逐个导入。大歌单自动分页读取；下次启动自动打开已登录账号的音乐库。
- QQ 音乐搜索、可选的公开歌单导入、同步歌词与翻译，以及按账号权限申请标准 / 高品质 / FLAC 播放地址。
- 哔哩哔哩 BV 链接解析、多分 P 音频、账号收藏夹分页读取。
- 内置平台网页登录窗口，以及平台原网页入口。接口播放失败时，可通过“打开平台页面”或歌曲旁的 ↗ 进入平台原网页。
- 登录 Cookie 使用 Windows 系统加密保存。网页会话独立存放，不读取用户其他浏览器中的账号信息。
- 音质按“所选音质 → 较低音质 → AAC 兼容音源”自动尝试，播放器显示实际音质。音频地址会先验证，解码或网络失败后有限重试并尝试恢复播放位置。
- 播放诊断记录取票、音频验证和播放器失败阶段，可在设置中保存诊断文件；记录不包含 Cookie、账号原值或带签名的音频地址。
- 歌词页支持弹性居中、动态高亮、远近层次和暂停自动跟随；手动滚动后可点击“回到当前歌词”。存在真实逐字时间数据时启用逐字填充，普通 LRC 仅显示逐行进度。
- 播放页从当前专辑封面动态提取背景色，切歌时渐变过渡；本地音乐可读取同目录 cover.jpg / cover.png / folder.jpg 或与歌曲同名的图片。
- 首页与底栏采用半透明玻璃质感、页面过渡和卡片反馈，并尊重系统“减少动态效果”偏好。
- 个人歌单支持名称搜索、数量或名称排序、封面 / 列表视图；歌单内支持歌曲和歌手筛选。

## 使用提示

1. 本地音乐：点击“本地音乐”→“添加音乐”或“导入文件夹”。
2. QQ 音乐：点击“我的 QQ 音乐”并登录，账号音乐库会自动出现。点击“我喜欢”、自建或收藏歌单即可听歌；“刷新音乐库”读取远端最新列表。手动导入只用于额外保存歌单副本。
3. 哔哩哔哩：选择对应音源，粘贴 BV 号或完整视频链接。短链接需先在浏览器展开。
4. 本机歌单：侧栏“我的歌单”旁的 + 创建；歌曲旁的 + 加入本机歌单。歌曲爱心保存到“本机收藏”，目前不会反向修改 QQ 账号的云端收藏。
5. 歌词：点击底部封面或“词”进入全屏页面，封面与播放控件平滑过渡；Esc 返回。切换布局和主题不会重新加载正在播放的音频。
6. 夜间模式：设置 → 外观 → 主题模式。默认“跟随 Windows”，也可固定为浅色或深色。跟随的是 Windows 的应用颜色模式。
7. 音量：点击扬声器按钮展开滑条；音量会保存。弹层打开时 Esc 只收起音量条，再按 Esc 才退出歌词页。
8. 快捷键：空格播放 / 暂停，Ctrl + 左右方向键切歌（焦点位于输入框或按钮时不拦截）；Esc 可从歌词全屏返回。

本地歌曲标题按文件名读取，推荐使用 `歌手 - 歌名.mp3`。当前不读取 ID3 封面和标题。LRC 需为 UTF-8 编码。

## 在线音源的实际限制

在线接口可能因登录状态、平台风控、地区或接口更新失败；不能将“已保存登录凭证”理解为账号已通过平台验证。自动降级只使用平台对当前账号签发的音源，不改变账号权限。

开发测试中，QQ 音乐已在已登录账号下成功读取个人歌单、播放在线歌曲并显示同步歌词。游客搜索或播放仍可能受限。哔哩哔哩已成功读取视频信息并获得 HTTP 206 音频片段，CDN 也出现过 HTTP 503。已加入备用音频地址尝试和平台原网页入口。

会员音质和所有私有内容未逐项验证。网页登录兼容性受平台控制，必要时可在设置中填写本人账号 Cookie。登录过期后需要重新登录，不实现自动续期。音源标记结合真实时长判断，避免仅根据 URL 参数将完整歌曲误标为试听。

## 尚未移植

原版个性化推荐流、网易云音乐、酷狗音乐、云端收藏双向同步、USB DAC 独占输出、APE / DSD 等专用解码、QQ 加密 QRC 解密、安卓特有手势及通知效果。当前 QQ 在线歌词主要使用 LRC；未把普通逐行歌词伪造成逐字时间数据。

“我的 QQ 音乐”内的“我喜欢”、自建与收藏歌单从账号读取；“本机收藏”及侧栏手动创建的歌单保存在此电脑。通过“导入 QQ 歌单”额外生成的本机副本不自动订阅远端变更。程序是桌面逻辑移植和界面重建，并非将全部 Android 代码直接编译为 Windows。

## 保存位置

当前发行包保存于 `%APPDATA%\MusicOne Windows\`。里面包含音乐列表、本机歌单、加密的登录凭证与独立网页会话，以及 playback-diagnostics.json。移动原音乐文件后，请重新导入。

开发期间曾出现的 0x80000003 弹窗来自受限命令进程中的 Electron 启动检查；正常 Windows 桌面入口已验证可启动。发布包保留 Electron 的标准安全设置，不需要以管理员身份运行。

## 开发与构建

源码没有额外运行依赖，仅需要 Electron。开发环境安装 Node.js 后：

```text
npm install
npm start
npm test
```

也可以使用 Python 3 标准库构建 Windows x64 便携版：

```text
python build_windows.py
```

构建脚本从 Electron 官方 GitHub Releases 下载指定版本，验证 SHA-256，再将本项目放入 resources/app。默认输出到源码目录下 `dist/MusicOne-Windows`。更换 Electron 版本时应同步 package.json 与 build_windows.py。
